# 配信（ホスティング）の手順

- 作成日: 2026-10-26
- 対象: 自分の iPhone でアプリを開けるようにするまで
- **決定（2026-10-26）: A の GitHub Pages を採用。リポジトリは公開に変更済み。配信 URL は https://lammratta.github.io/sg-study/ 。`main` に push すると GitHub Actions（`.github/workflows/pages.yml`）が `public/` を配信する。**

## 1. なぜ「配信」が必要か

このアプリは PWA（Web ページをホーム画面に追加して使う形式）なので、iPhone の Safari で開ける場所（URL）に一度置く必要があります。最初に URL を開いてホーム画面に追加すれば、以後はオフラインでも動きます。学習記録は iPhone の中にだけ保存され、配信先には送られません。

配信先は、GitHub のリポジトリ `lammratta/sg-study` に `git push` するたびに自動で更新されます。

## 2. 2 つの選択肢

| | A. GitHub Pages | B. Cloudflare Pages |
|---|---|---|
| 新しいアカウント | 不要（今の GitHub アカウントだけ） | Cloudflare の無料アカウントを作る |
| リポジトリ | **公開に変える必要がある**（GitHub 無料プランの制約） | 非公開のままでよい |
| 設定作業 | Claude がすべて行う（本人の作業なし） | 本人が Cloudflare の画面で 5 分ほど操作（下記の手順） |
| アプリの URL | `https://lammratta.github.io/sg-study/` | `https://sg-study.pages.dev` |
| 外から見えるもの | アプリの URL と、リポジトリの中身（問題データ・解説・アプリのコード） | アプリの URL だけ（コードは非公開のまま） |

どちらを選んでも、アプリの URL 自体は知っている人なら誰でも開けます。中身は IPA が公開している問題と自作の解説だけで、学習記録は端末内にあるので他人には見えません。

**おすすめ**: 手間を最小にするなら A（公開リポジトリ + GitHub Pages）。リポジトリを非公開のままにしたいなら B。

## 3. A を選んだ場合（Claude が実施）

1. リポジトリを公開に変更する: `gh repo edit lammratta/sg-study --visibility public`
2. GitHub Actions のワークフロー（`.github/workflows/pages.yml`）で `public/` を配信する設定を追加し、push する
3. 1〜2 分後に `https://lammratta.github.io/sg-study/` が開ける
4. iPhone の Safari でその URL を開き、「共有」→「ホーム画面に追加」

## 4. B を選んだ場合（本人が 5 分）

1. https://dash.cloudflare.com/sign-up で無料アカウントを作る（メールアドレスとパスワードのみ）
2. 左メニュー「Workers & Pages」→「Create」→「Pages」タブ →「Connect to Git」
3. GitHub との連携を許可し、リポジトリ `lammratta/sg-study` を選ぶ
4. Build settings を次のとおりにする
   - Framework preset: None
   - Build command: （空欄）
   - Build output directory: `public`
5. 「Save and Deploy」を押す。1〜2 分で `https://sg-study.pages.dev` が発行される
6. iPhone の Safari でその URL を開き、「共有」→「ホーム画面に追加」

以後は、`git push` のたびに自動で更新されます。

## 5. 設定後の確認（どちらも）

- iPhone でホーム画面から起動すると、Safari のアドレスバーが無い全画面で開く
- 機内モードにしても起動できる（Phase 1 の Service Worker 実装後）
- 設定画面で「バックアップ」が「ファイル」アプリに保存できる（Phase 1）
