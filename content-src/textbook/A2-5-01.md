## 要点

- デジュールスタンダードは公的な標準化機関が定めた規格、デファクトスタンダードは市場での普及により事実上の標準になったもの
- ISOは国際標準化機構、IECは電気・電子分野、ISO/IEC JTC 1は両者の情報技術合同委員会、ITU-Tは電気通信、IEEEはLANなど、IETFはインターネット技術（RFC）、W3CはWeb技術を担当する
- JIS（日本産業規格）は産業標準化法に基づき、JISC（日本産業標準調査会）の審議を経て主務大臣が制定する。JIS Q 27001はISO/IEC 27001を翻訳した国内規格
- ISMSの要求事項はISO/IEC 27001、管理策の実践の手引はISO/IEC 27002、クラウドの管理策は27017、プライバシー情報マネジメントは27701
- ISO 31000はリスクマネジメントの指針で認証規格ではない。PCI DSSはカード会員データを守る業界基準、NIST CSFはサイバーセキュリティ対策の枠組み
- JIS Q 15001は個人情報保護マネジメントシステムの規格でプライバシーマークの基準

## 解説

### 標準化の意義と標準の種類

標準化とは、製品やサービス、手順について共通のルール（規格）を定めることで、互換性の確保、品質の保証、取引の円滑化をもたらす。情報セキュリティでも、管理の仕組みを共通の規格に合わせることで、取引先や顧客に対策の水準を客観的に示せる。

標準には成り立ちによる区別がある。デジュールスタンダード（デジュレスタンダード）は、ISOやJISのように公的な標準化機関が正式な手続で定めた規格である。デファクトスタンダードは、WindowsやPDFのように特定の製品や仕様が市場で広く使われた結果、事実上の標準となったものである。業界団体やコンソーシアムが協議して定めるフォーラム標準（W3Cの勧告やBluetoothなど）はその中間に位置する。

### 主な標準化団体

| 団体 | 役割 | 代表例 |
| --- | --- | --- |
| ISO（国際標準化機構） | 電気・電子以外の幅広い分野の国際規格（IS）を制定する非政府機関 | ISO 9001、ISO 31000 |
| IEC（国際電気標準会議） | 電気・電子技術分野の国際規格 | IEC 62443（制御システムセキュリティ） |
| ISO/IEC JTC 1 | ISOとIECが情報技術分野で設けた合同技術委員会 | ISO/IEC 27001、ISO/IEC 15408 |
| ITU-T | 国際電気通信連合の電気通信標準化部門。勧告を発行 | X.509（電子証明書） |
| IEEE（米国電気電子学会） | 電気・電子・情報分野の学会で、LAN規格などを策定 | IEEE 802.3（イーサネット）、802.11（無線LAN）、802.1X（認証） |
| IETF | インターネット技術の標準化団体。仕様はRFCとして公開 | TCP/IP、HTTP、TLS |
| W3C | Web技術の標準化団体。仕様を勧告として公開 | HTML、CSS、XML |
| JISC（日本産業標準調査会） | 経済産業省に置かれ、JISの制定・改正を審議し、ISO・IECに日本代表として参加 | JIS全般 |

JIS（日本産業規格）は産業標準化法に基づく国家規格で、2019年に「工業規格」から「産業規格」に改称された。情報処理分野はJIS X、マネジメントシステムはJIS Qの記号が付く。国際規格をそのまま翻訳したJIS（JIS Q 27001:2023はISO/IEC 27001:2022に対応）を使えば、国際規格と整合した取組みができる。

### ISMS関連規格（ISO/IEC 27000シリーズ）

| 規格 | 内容 |
| --- | --- |
| ISO/IEC 27000 | ISMSの概要と用語 |
| ISO/IEC 27001（JIS Q 27001:2023） | ISMSの要求事項。第三者認証（ISMS適合性評価制度）の審査基準 |
| ISO/IEC 27002（JIS Q 27002:2024） | 情報セキュリティ管理策の実践の規範。2022年版で組織的・人的・物理的・技術的の4テーマ93管理策に再編 |
| ISO/IEC 27005 | 情報セキュリティリスクマネジメントの指針 |
| ISO/IEC 27017（JIS Q 27017） | クラウドサービスに関する情報セキュリティ管理策。ISMSクラウドセキュリティ認証の基準 |
| ISO/IEC 27018 | パブリッククラウドにおける個人情報（PII）保護の実践規範 |
| ISO/IEC 27701 | プライバシー情報マネジメントシステム（PIMS）。27001・27002に個人情報保護の要求事項を拡張 |

27001が「何を満たすべきか」を定める認証用の規格で、27002はそれを実現する管理策の手引という関係である。27002自体での認証は行われない。ISO/IEC 15408（コモンクライテリア）はIT製品・システムのセキュリティ機能を評価・認証する規格で、組織のマネジメントを対象とする27001とは対象が異なる。

### その他のマネジメントシステム規格と業界基準

ISO 31000（JIS Q 31000）はあらゆる組織のリスクマネジメントの原則と指針を示す規格で、要求事項ではないため認証の対象にならない。ISO 9001は品質マネジメントシステム、ISO 14001は環境マネジメントシステムの要求事項で、ISMSと同じPDCAの考え方に基づく。ISO/IEC 20000はITサービスマネジメント、ISO 22301は事業継続マネジメントの規格である。JIS Q 15001は個人情報保護マネジメントシステム（PMS）の要求事項を定めた日本独自の規格で、JIPDECが運営するプライバシーマーク制度の審査基準になっている。

PCI DSSは、国際カードブランドが設立したPCI SSCが策定したカード会員データ保護の基準で、カード情報を保存・処理・伝送する加盟店や決済代行事業者に、ネットワークの保護、カード番号の暗号化、アクセス制御、定期的な脆弱性検査などの12の要件を求める。法律ではなく業界の契約上の基準である。

### NISTの文書

米国のNIST（国立標準技術研究所）の文書は米国政府向けだが世界的に参照される。サイバーセキュリティフレームワーク（CSF）は、対策を「統治（Govern）、識別、防御、検知、対応、復旧」の6つの機能に整理した枠組みで、2024年の2.0版で統治が加わった。SP 800シリーズはセキュリティの技術・運用に関する文書群で、SP 800-53（管理策カタログ）、SP 800-61（インシデント対応）、SP 800-63（デジタルアイデンティティ）、SP 800-171（政府の機密でない重要情報を扱う民間組織の要件）、SP 800-207（ゼロトラスト）が代表的である。

### 文字コード・バーコードなどの標準化例

情報の表現にも標準化が欠かせない。文字コードでは、英数字のASCII、日本語のJIS X 0208やShift_JIS、EUC-JP、世界中の文字を統一して扱うUnicode（ISO/IEC 10646と対応。符号化方式はUTF-8が主流）があり、不一致は文字化けの原因になる。バーコードでは、商品識別のJANコード（国際的にはEAN）や二次元コードのQRコード（JIS X 0510、ISO/IEC 18004）が標準化されている。脆弱性を一意に識別するCVEや深刻度を評価するCVSSも、セキュリティ情報を共有するための事実上の標準である。

## 試験での問われ方

- 「デファクトスタンダードの説明として適切なもの」は「市場で広く普及して事実上の標準になったもの」。公的機関が定めたものはデジュール
- 標準化団体と担当分野の対応（IEEEとLAN、IETFとRFC、W3CとWeb、ITU-TとX.509）は入替えのひっかけが出る
- ISO/IEC 27001は「要求事項・認証」、27002は「管理策の手引・認証なし」。27017はクラウド、27701はプライバシーという枝番の対応
- ISO 31000は「リスクマネジメントの指針で認証規格ではない」が頻出の正解
- JIS Q 15001とプライバシーマーク、ISO/IEC 27001とISMS認証の組合せを混同させる選択肢に注意
- PCI DSSは「法律」ではなく「クレジットカード業界の基準」

## 用語集

- **標準化**: 製品・サービス・手順について共通のルールを定めること。互換性、品質、安全性の確保が目的。
- **JIS（日本産業規格）**: 産業標準化法に基づく日本の国家規格。JISCの審議を経て主務大臣が制定する。
- **IS（国際規格）**: ISOやIECが制定する国際的な規格。各国の国家規格の基礎になる。
- **ISO（国際標準化機構）**: 電気・電子分野以外の幅広い国際規格を制定する非政府機関。
- **IEC（国際電気標準会議）**: 電気・電子技術分野の国際規格を制定する機関。
- **ISO/IEC JTC 1**: ISOとIECが情報技術分野のために設けた合同技術委員会。ISO/IEC 27001などを担当する。
- **ITU-T**: 国際電気通信連合の電気通信標準化部門。X.509など通信関連の勧告を発行する。
- **IEEE**: 米国電気電子学会。IEEE 802.3（イーサネット）、802.11（無線LAN）などのLAN規格を策定する。
- **IETF**: インターネット技術の標準化団体。仕様をRFCとして公開する。
- **RFC**: IETFが公開するインターネット技術の仕様文書。TCP/IPやHTTPなどが定められている。
- **W3C**: Web技術の標準化団体。HTML、CSS、XMLなどを勧告として公開する。
- **JISC（日本産業標準調査会）**: 経済産業省に置かれ、JISの制定・改正を審議し、ISO・IECに日本代表として参加する機関。
- **デジュレスタンダード**: 公的な標準化機関が正式な手続で定めた規格。デジュールスタンダードともいう。
- **デファクトスタンダード**: 市場で広く使われた結果、事実上の標準となった製品や仕様。
- **フォーラム標準**: 業界団体やコンソーシアムが協議して定めた標準。
- **ISO/IEC 27000シリーズ**: ISMSに関する国際規格群。27000（用語）、27001（要求事項）、27002（管理策）、27017（クラウド）、27701（プライバシー）など。
- **ISO/IEC 27001**: ISMSの要求事項を定めた規格。JIS Q 27001:2023として国内規格化され、ISMS認証の審査基準となる。
- **ISO/IEC 27002**: 情報セキュリティ管理策の実践の規範。JIS Q 27002:2024に対応し、4テーマ93管理策で構成される。
- **ISO/IEC 27017**: クラウドサービスの情報セキュリティ管理策の規格。ISMSクラウドセキュリティ認証の基準。
- **ISO/IEC 27701**: プライバシー情報マネジメントシステム（PIMS）の規格。ISMSに個人情報保護の要求事項を加える。
- **ISO/IEC 15408**: IT製品・システムのセキュリティ機能を評価・認証する規格（コモンクライテリア）。
- **ISO 31000**: リスクマネジメントの原則と指針を示す規格。要求事項ではなく認証の対象にならない。
- **ISO 9001**: 品質マネジメントシステムの要求事項を定めた規格。
- **ISO 14001**: 環境マネジメントシステムの要求事項を定めた規格。
- **JIS Q 15001**: 個人情報保護マネジメントシステム（PMS）の要求事項を定めた日本の規格。プライバシーマークの審査基準。
- **PCI DSS**: 国際カードブランドが設立したPCI SSCによるカード会員データ保護の基準。12の要件からなる業界基準。
- **NIST CSF**: 米国NISTのサイバーセキュリティフレームワーク。統治・識別・防御・検知・対応・復旧の6機能で対策を整理する。
- **NIST SP 800シリーズ**: NISTが公開するセキュリティの技術・運用文書群。SP 800-53、SP 800-61、SP 800-171などがある。
- **Unicode**: 世界中の文字を統一して扱う文字コード体系。UTF-8などの符号化方式で表現する。
- **QRコード**: 日本で開発された二次元コード。JIS X 0510およびISO/IEC 18004として標準化されている。
