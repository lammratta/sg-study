## 要点

- **ISMS**は、組織が情報セキュリティを計画（Plan）・実施（Do）・点検（Check）・改善（Act）のサイクルで継続的に運用する仕組みである
- JIS Q 27001:2023はISMSの「要求事項」（認証の審査対象）、JIS Q 27002:2024は管理策の「実践の規範」（手引）という役割の違いがある。**認証審査の基準**になるのは27001だけ
- JIS Q 27001の本文は、組織の状況・リーダーシップ・計画・支援・運用・パフォーマンス評価・改善の**7つの箇条**で構成される
- 管理策は組織的・人的・物理的・技術的の4テーマに分類され、**適用宣言書**で採用・不採用とその理由を明示する
- 内部監査とマネジメントレビューはパフォーマンス評価、不適合に対する**是正処置**と継続的改善は改善の箇条に当たる
- **ISMS適合性評価制度**では、認定を受けた認証機関が第三者として審査し、適合する組織にISMS認証を与える

## 解説

### ISMSとは何か

**ISMS**（Information Security Management System）は、情報セキュリティを「一度対策して終わり」にせず、組織として方針を決め、リスクアセスメントに基づいて管理策を実施し、結果を点検して改善し続ける仕組みである。

その枠組みがJIS Q 27000シリーズで、主な規格の役割は次のとおりである。

| 規格 | 扱う内容 |
| --- | --- |
| JIS Q 27000 | 用語（是正処置、リスクレベルなどの定義） |
| JIS Q 27001 | ISMSの要求事項。認証審査の基準になる |
| JIS Q 27002 | 管理策の手引（実践の規範） |
| JIS Q 27005 | 情報セキュリティリスクマネジメントの手引 |
| JIS Q 27014 | 情報セキュリティガバナンス |
| JIS Q 27017 | クラウドサービスの管理策 |

**認証審査の基準になるのはJIS Q 27001だけ**である。

運用の基本は**PDCA**サイクルで、次の4段階を繰り返す。

- **Plan**: リスクアセスメントを行い、対策の計画を立てる
- **Do**: 管理策を導入し、運用する
- **Check**: 監視・測定、内部監査、マネジメントレビューで点検する
- **Act**: 是正処置と改善を行い、次の計画につなげる

### JIS Q 27001:2023の要求事項

JIS Q 27001:2023（ISO/IEC 27001:2022に対応）の本文は、箇条4から箇条10までの7つで構成される。

| 箇条 | 名称 | 主な内容 |
| --- | --- | --- |
| 4 | 組織の状況 | 内外の課題、利害関係者のニーズ、ISMS適用範囲の決定 |
| 5 | リーダーシップ | トップマネジメントの関与、情報セキュリティ方針、役割と責任 |
| 6 | 計画 | リスクアセスメントとリスク対応、情報セキュリティ目的 |
| 7 | 支援 | 資源、力量、認識、コミュニケーション、文書化した情報 |
| 8 | 運用 | 計画した活動の実施、リスクアセスメントとリスク対応の実行 |
| 9 | パフォーマンス評価 | 監視・測定、内部監査、マネジメントレビュー |
| 10 | 改善 | 継続的改善、不適合及び是正処置 |

トップマネジメント（経営層）は、方針を定め、資源を確保し、ISMSに責任をもつことが求められる。適用範囲は事業所や部門、システムの単位で組織が決めるが、境界を明確にして文書化する。

計画の箇条では、リスク対応に必要な管理策を決め、附属書Aと比べて漏れがないか確かめる。そのうえで、採用する管理策と除外する管理策、その理由、実施状況を記した**適用宣言書**（SoA）を作成する。

### JIS Q 27002:2024の管理策

JIS Q 27002:2024（ISO/IEC 27002:2022に対応）は、JIS Q 27001の附属書Aに並ぶ93の管理策について、目的と実施の手引を示す。管理策は4つのテーマに分類される。

- **組織的管理策**: 方針、役割、資産管理、情報の分類とラベル付け、供給者（委託先・クラウド）との関係、インシデント管理、事業継続、法令順守など
- **人的管理策**: 採用時の選考、教育・訓練、懲戒手続など
- **物理的管理策**: 入退室管理、装置の保護、クリアデスク・クリアスクリーン、媒体の廃棄など
- **技術的管理策**: 特権アクセス権、マルウェア対策、バックアップ、ログ取得、暗号、ネットワークの分離など

各管理策には属性が付けられ、**管理策タイプ**（予防・検知・是正）や**サイバーセキュリティ概念**（識別・防御・検知・対応・復旧）で横断的に整理できる。

### アカウント管理と利用者アクセス権

利用部門に関係が深い管理策として、**アカウント管理**と利用者アクセス権の管理がある。アクセス権は、必要な人に必要な範囲だけ与える**need-to-know**（最小権限）の原則に従い、異動・退職時に速やかに見直す。

利用者IDは個人ごとに発行し、共用しない。個人別のIDがあって初めて、誰が操作したかを追跡でき、IDごとに設定したアクセス権が意味をもつ。

共用端末のWebブラウザにIDとパスワードを保存すると、次にその端末を使った人が前の人のIDでログインでき、**本来は権限のない情報にアクセスできてしまう**。個人別のIDとアクセス権による管理が無効になるため、共用端末では認証情報を保存させず、使い終わったら必ずログアウトする。

### 外部委託とクラウドサービスの利用

外部委託やクラウドサービスを使っても、情報セキュリティの**責任は委託元に残る**。委託先は、契約の前後を通じて次のように管理する。

- 契約前: 秘密保持契約を結んだうえで委託先を訪問するなどして、管理体制や設備を確かめ、委託に伴うリスクを評価する
- 契約時: 必要な管理策、再委託の条件、事故発生時の報告、監査への協力などを契約で定める
- 契約後: 報告を受けたり点検したりして、取り決めが守られているかを定期的に確かめる

委託先の評価では、委託先がすでに講じている対策で抑えられているリスクと、まだ残っているリスクを切り分ける。機器やサービスの初期設定（初期パスワード、通知メールの差出人や件名など）は、マニュアルなどで公開されていることが多い。**初期設定のまま使うと、攻撃者に推測されたり、正規の通知を装った偽のメールを作られたりしやすい**。

クラウドでは、基盤の保護は事業者、データやアカウントの管理は利用者という**責任共有モデル**を理解し、自社が担う部分を明確にする（新制度で追加: クラウドの観点）。

### パフォーマンス評価と改善

パフォーマンス評価では、まず管理策の**有効性**（計画した活動が実行され、計画した結果が達成された程度）を監視・測定する。中心になる活動は、内部監査とマネジメントレビューである。

| 活動 | 行う人 | 内容 |
| --- | --- | --- |
| 内部監査 | 監査対象から独立した立場の人 | ISMSが規格と組織自身の要求事項に適合し、有効に実施・維持されているかを計画的に検証する |
| マネジメントレビュー | トップマネジメント | 監査結果、不適合と是正処置の状況、リスクアセスメントの結果などを定期的にレビューし、改善の機会や必要な変更を決定する |

各部門が点検項目に沿って自らの実施状況を確かめる**自己点検**（自己評価）も、監視・測定の手段として使われる。**評価の根拠は「ルールがある」ことではなく、ルールどおりに実施されている事実を確かめたこと**である。

事実は、記録の確認、現場の観察、担当者へのヒアリングなどで確かめる。決められたとおりに実施していなくても、別の手段で同程度にリスクを抑えている場合は、その代わりの管理策を具体的な根拠として示す。

不適合（要求事項を満たしていない状態）への対応は、次のように区別する。

| 用語 | 意味 |
| --- | --- |
| 修正 | 見つかった不適合そのものを取り除く処置。その場の手当てで、原因の除去は含まない |
| 是正処置 | 不適合の原因を取り除き、再発を防ぐ処置 |
| 継続的改善 | パフォーマンスを高めるために繰り返し行う活動。個々の不適合に限らず、ISMS全体を良くしていく |

不適合には修正だけで終わらせず、**原因を除去する是正処置**まで行って再発を防ぐ。

### ISMS適合性評価制度と認証

**ISMS適合性評価制度**は、組織のISMSがJIS Q 27001に適合しているかを第三者が審査し、認証する仕組みである。認定機関（ISMS-AC: 情報マネジメントシステム認定センター）が認証機関を認定し、認証機関が組織を審査してISMS認証を与える。

認証は適用範囲に対して与えられ、登録後も定期的な維持審査と、3年ごとの再認証審査を受ける。なお、経営層が情報セキュリティを方向付け、監督する活動は**情報セキュリティガバナンス**（JIS Q 27014）と呼び、ISMSの運営（マネジメント）とは区別される。

## 試験での問われ方

- JIS Q 27001は「**要求事項**」、JIS Q 27002は「管理策の手引」。認証の審査基準になるのは27001という違いを問う
- 内部監査とマネジメントレビューの主体と目的を入れ替えた選択肢が出る。内部監査は**独立した立場の人**が適合性と有効性を検証し、マネジメントレビューはトップマネジメントが行う
- 適用宣言書は「**採用する管理策と除外する管理策、その理由**を示す文書」で、リスクアセスメント結果を記した文書ではない。管理策の4テーマは具体例で問われる（入退室管理は物理的、教育は人的、バックアップは技術的）
- 是正処置は「不適合の**原因を除去**して再発を防ぐ処置」。不適合そのものを取り除くだけの「修正」と区別する
- クラウドの責任共有モデルでは「**データやアクセス権の管理は利用者の責任**」。事業者任せにできるとする選択肢は誤り
- 科目Bでは、監査や自己点検の場面が出る。指摘された事実から**無効になる管理策**をたどってリスクを特定し、評価の根拠には「実施されている事実の確認」を選ぶ

## 用語集

- **ISMS**: 情報セキュリティを組織的・継続的に管理する仕組み。JIS Q 27001が要求事項を定める。
- **JIS Q 27000**: ISMSに関する規格群の概要と用語を定めた規格。是正処置やリスクレベルなどを定義する。
- **JIS Q 27001（ISO/IEC 27001）**: ISMSの要求事項を定めた規格。2023年版が最新で、認証審査の基準になる。
- **JIS Q 27002（ISO/IEC 27002）**: 情報セキュリティ管理策の実践の規範。2024年版が最新で、93の管理策の手引を示す。
- **ISMS適用範囲**: ISMSを適用する組織・事業所・システムの範囲。境界を明確にして文書化する。
- **リーダーシップ**: トップマネジメントがISMSに関与し、方針を定め、資源を確保し責任をもつこと。
- **計画**: リスクアセスメントとリスク対応、情報セキュリティ目的を定める箇条。
- **運用**: 計画した管理策とプロセスを実施し、リスクアセスメントとリスク対応を実行する箇条。
- **パフォーマンス評価**: 監視・測定、内部監査、マネジメントレビューによってISMSの有効性を評価する箇条。
- **内部監査**: 独立した立場の人がISMSの適合性と有効性を計画的に検証する活動。
- **マネジメントレビュー**: トップマネジメントがISMSの状況を定期的にレビューし、改善や変更を決定する活動。
- **改善**: 不適合及び是正処置と継続的改善を扱う箇条。
- **不適合及び是正処置**: 要求事項を満たしていない状態を修正し、原因を除去して再発を防ぐ処置。
- **修正**: 見つかった不適合そのものを取り除く処置。原因の除去や再発防止までは含まない。
- **継続的改善**: ISMSの適切性・妥当性・有効性を繰り返し高めていく活動。
- **適用宣言書**: 採用する管理策と除外する管理策、その理由、実施状況を記した文書。
- **管理目的**: 管理策を実施することで達成しようとする目的。
- **情報セキュリティ管理策**: リスクを修正するための手段。組織的・人的・物理的・技術的の4テーマに分類される。
- **管理策タイプ**: 管理策を予防・検知・是正のどの働きをもつかで分類する属性。
- **サイバーセキュリティ概念**: 管理策を識別・防御・検知・対応・復旧のどの機能に当たるかで分類する属性。
- **有効性**: 計画した活動が実行され、計画した結果が達成された程度。
- **ISMS適合性評価制度**: 組織のISMSがJIS Q 27001に適合しているかを第三者が審査・認証する制度。
- **ISMS認証**: 認定された認証機関の審査に合格した組織に与えられる認証。適用範囲単位で登録される。
- **情報セキュリティガバナンス（JIS Q 27014）**: 経営層が情報セキュリティを方向付け、監督する枠組み。ISMSの運営と区別される。
- **PDCA**: Plan・Do・Check・Actを繰り返して改善する管理のサイクル。
- **アカウント管理**: 利用者IDの登録・変更・削除を適切に行い、不要なアカウントを残さない管理。
- **need-to-know（最小権限）の原則**: 業務上必要な人に、必要な情報と権限だけを与える考え方。
- **クラウドサービスの責任共有モデル**: 基盤の保護はクラウド事業者、データやアカウントの管理は利用者というように責任を分担する考え方。
- **外部委託やクラウドサービスの利用時における情報セキュリティ**: 委託先・事業者の管理状況を確認し、契約で義務を定めて監督すること。責任は委託元に残る。
- **サイバーハイジーン**: 更新プログラムの適用や不要アカウントの削除など、基本的な衛生管理を日常的に続けること。
