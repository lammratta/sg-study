## 要点

- サイバーセキュリティ基本法は国の基本方針と国・地方公共団体・事業者などの責務を定める法律で、事業者の責務は**努力義務**。内閣にサイバーセキュリティ戦略本部を置き、事務局は国家サイバー統括室（2025年7月にNISCから改組）
- 不正アクセス行為は「他人の識別符号の入力（なりすまし）」「セキュリティホール攻撃」「他のコンピュータ経由のセキュリティホール攻撃」の3類型。**ネットワーク経由**でアクセス制御機能のあるコンピュータへの行為だけが対象
- 不正アクセス禁止法は、不正アクセス行為そのものに加え、識別符号の不正取得・不正保管、**助長行為**（他人のID・パスワードの無断提供）、フィッシングも処罰する。アクセス管理者の防御措置は努力義務で罰則なし
- 刑法は、ウイルス作成罪（不正指令電磁的記録に関する罪）、**電子計算機損壊等業務妨害罪**（DoS攻撃・改ざん）、電子計算機使用詐欺罪（不正なデータで財産上の利益）を規定。記憶媒体経由のマルウェアによる破壊も刑法で処罰される
- **電子署名法**は、本人による電子署名がある電子文書を真正に成立したものと推定する（押印と同様の効力）。プロバイダ責任制限法は2025年4月に情報流通プラットフォーム対処法へ改称され、大規模プラットフォーム事業者に削除申出への対応義務が加わった
- 特定電子メール法は広告宣伝メールに**オプトイン**（事前同意）を義務づけ、送信者と送信委託者を規制する。電気通信事業法は通信の秘密を保護する

## 解説

### サイバーセキュリティ基本法

**サイバーセキュリティ基本法**は2014年に成立した基本法で、国の施策の基本理念と、関係する主体の責務を定める。責務が定められているのは次の主体である。

- 国・地方公共団体
- 重要社会基盤事業者（電力・金融・交通などの重要インフラ事業者）
- サイバー関連事業者、教育研究機関
- 国民（努力）

**個々の企業に具体的な対策を強制したり、罰則を科したりする法律ではない**。事業者には「自主的かつ積極的にサイバーセキュリティの確保に努める」という**努力義務**が課される。

この法律は、次の状態を「サイバーセキュリティ」と定義している。情報の漏えい・滅失・毀損の防止などの安全管理と、情報システム・ネットワークの安全性・信頼性の確保に必要な措置が講じられ、その状態が適切に維持管理されていることである。

推進体制は次のとおり。

- **サイバーセキュリティ戦略本部**: 内閣に置かれ、サイバーセキュリティ戦略の案を作る。戦略は閣議決定される
- 事務局: 内閣サイバーセキュリティセンター（NISC）が担ってきたが、2025年7月1日に**国家サイバー統括室**へ改組された
- **サイバーセキュリティ協議会**: 2018年の改正で設けられた、官民が脅威情報を共有する枠組み。構成員には守秘義務が課される

### 不正アクセス禁止法

**不正アクセス禁止法**（不正アクセス行為の禁止等に関する法律）は、次の条件を満たす行為を**不正アクセス行為**と定義し、禁止する。

- 電気通信回線（ネットワーク）を通じて行う
- **アクセス制御機能**（ID・パスワードなどの識別符号で利用を制限する機能）を持つ特定電子計算機が対象
- 次の表の3類型のいずれかで、制限されている機能を利用できる状態にする

| 類型 | 内容 | 例 |
| --- | --- | --- |
| なりすまし | 他人の識別符号を入力して利用できる状態にする | 盗んだID・パスワードでログインする、パスワードを推測して当てる |
| セキュリティホール攻撃 | 識別符号以外の情報や指令を入力して制限を免れる | 脆弱性を突いて認証を回避して侵入する |
| 他のコンピュータ経由 | 別のコンピュータを経由して制限を免れる | 踏み台経由で侵入する |

判断のポイントは「**ネットワーク経由**」と「**アクセス制御機能がある**」の2つである。次の行為は不正アクセス行為に当たらない。

- 他人のパソコンを目の前で直接操作する
- 認証のないサーバにアクセスする
- USBメモリなどの記憶媒体を使ってマルウェアを持ち込む（ネットワーク経由ではない。刑法の罪になる）

**未遂は処罰されない**が、ログインできた時点で成立し、その後データを盗んだかどうかは問わない。

この法律は、不正アクセス行為のほかに次の行為も処罰する。

- 他人の識別符号の不正取得
- 不正アクセス目的での識別符号の保管
- **助長行為**: 業務その他正当な理由なく、他人の識別符号を管理者や本人以外の第三者に提供する
- 識別符号の入力を不正に要求する行為: フィッシングサイトの設置やフィッシングメールの送信

一方、**アクセス管理者**には、識別符号の適切な管理やアクセス制御機能の高度化などの防御措置を講じる努力義務がある。**怠っても罰則はない**。

### 刑法のサイバー犯罪

| 罪名 | 行為 | 典型例 |
| --- | --- | --- |
| 不正指令電磁的記録に関する罪（ウイルス作成罪、168条の2・168条の3） | 正当な理由なく、人のコンピュータで実行させる目的でウイルスを作成・提供・供用（実行させる）・取得・保管する | マルウェアの作成、メール添付での送付 |
| 電子計算機損壊等業務妨害罪（234条の2） | 業務に使うコンピュータやデータを損壊し、または虚偽の情報・不正な指令を与えて動作を妨げ、業務を妨害する。未遂も処罰 | DoS攻撃、Webサイトの改ざん |
| 電子計算機使用詐欺罪（246条の2） | コンピュータに虚偽の情報や不正な指令を与えて財産権の得喪に関する不実の電磁的記録を作り、財産上不法の利益を得る | 他人のクレジットカード情報で電子マネーを取得する |
| 電磁的記録不正作出及び供用罪（161条の2） | 権利・義務・事実証明に関する電磁的記録を不正に作る、または使う | 預金残高データの改ざん |
| 支払用カード電磁的記録不正作出等罪（163条の2など） | クレジットカードなどの磁気情報を不正に作る、所持する、情報を取得する | スキミング、偽造カードの作成 |

**電磁的記録**とは、電子的・磁気的な方式で作られ、コンピュータで処理される記録（電子データ）のことである。

**ウイルス作成罪**は「正当な理由がない」ことが要件なので、ウイルス対策の研究のために作成する行為は処罰されない。なお、2025年6月から懲役・禁錮は拘禁刑に一本化されている。

### 事例から罪名・法律を見分ける

事例問題では、「何に対して、何をしたか」で罪名や法律を見分ける。

| 行為の例 | 当てはまる罪・法律 |
| --- | --- |
| 業務に使うサーバのデータを消去・改ざんする、DoS攻撃でサービスを止める | 電子計算機損壊等業務妨害罪 |
| マルウェアを作る、メールやUSBメモリで他人のPCに仕込む | 不正指令電磁的記録に関する罪 |
| 不正に入手したカード情報をシステムに入力して電子マネーを得る | 電子計算機使用詐欺罪 |
| ネット上で人をだまして代金を支払わせる | 刑法の詐欺罪（246条） |
| 他人のソフトウェアや文章を無断で複製・販売・掲載する | 著作権法違反 |

**電子計算機使用詐欺罪はコンピュータを欺く罪**で、人をだまして金銭を払わせれば、ネット上でも通常の詐欺罪になる。

1つの行為が複数の罪に当たることもある。たとえば、ネットワーク経由で業務用のサーバに侵入してデータを消せば、侵入は不正アクセス禁止法違反、データの消去は電子計算機損壊等業務妨害罪になる。

### 電子署名法

**電子署名法**（電子署名及び認証業務等に関する法律）は、電子文書に押印と同じような証拠としての力を与える法律である。

この法律でいう**電子署名**は、電磁的記録に記録できる情報について行う措置で、次の2つを満たすものをいう。

- **本人性**: 本人が作成したことを示す
- **非改ざん性**: 改変されていないかを確認できる

紙への署名や印影のように、電磁的記録でないものは対象外である。法律は特定の暗号技術に限定していないが、実際には**公開鍵暗号を使うデジタル署名**が主流である。

紙の文書では、本人の署名や押印があれば、その文書は真正に成立した（本人の意思で作られた）ものと推定される（民事訴訟法）。電子署名法は、**本人だけが行える電子署名が付された電磁的記録も、真正に成立したものと推定する**と定めている。つまり、電子署名に押印と同様の効力を認めている。

電子証明書を発行する**認証業務**は、民間の事業者も行える。一定の基準を満たす認証業務について主務大臣の認定を受けた事業者が、**認定認証事業者**である。**認定は任意**で、認定がなければ電子署名が無効になるわけではない。

### 情報流通プラットフォーム対処法（旧プロバイダ責任制限法）

**旧プロバイダ責任制限法**は、ネット上の誹謗中傷や権利侵害の投稿について、次の2つを定めていた。

- 損害賠償責任の制限: プロバイダ（SNS事業者や掲示板管理者を含む）が投稿を削除した場合・しなかった場合の責任を制限する
- **発信者情報開示請求**: 被害者が、投稿者の氏名・IPアドレスなどの開示を求められる

改正の流れは次のとおり。

- 2021年の改正: 裁判所による発信者情報開示命令の手続が加わった
- 2024年の改正（2025年4月1日施行）: **情報流通プラットフォーム対処法**に改称された

2024年の改正では、総務大臣が指定する大規模プラットフォーム事業者に、次の義務が課された。

- 削除申出の窓口・手続の整備と公表
- 申出から一定の期間内に削除するかどうかを判断し、申出者に通知する
- 削除基準の策定・公表
- 運用状況の公表

### 特定電子メール法

**特定電子メール法**（特定電子メールの送信の適正化等に関する法律）は、広告や宣伝のための電子メール（特定電子メール）の送信を規制する法律である。目的は、一度に大量に送られるメールによる送受信上の支障を防ぎ、電子メールを利用しやすい環境を整えることである。

規制の対象は、メールを送る**送信者**と、送信を他の事業者に委託した**送信委託者**（広告主など）である。携帯電話番号宛てに送るSMS（ショートメッセージ）も対象になる。

主なルールは次のとおり。

- **オプトイン**: あらかじめ同意した相手にだけ送信できる。同意を得たことを示す記録は保存する
- 表示義務: 送信者の氏名・名称や住所、受信拒否の連絡先などをメールに表示する
- 受信拒否の尊重: 受信拒否の通知を受けた相手には、それ以降送信できない
- 禁止事項: 送信者情報を偽った送信、プログラムで作った架空のアドレス宛ての送信

**同意なしに送って受信拒否の手段だけ付けるオプトアウト方式は認められない**。2008年の改正で、オプトアウト方式からオプトイン方式に変わった。

例外として、取引関係にある相手、名刺などで自らアドレスを通知した相手、アドレスを公表している団体や営業を営む個人には、同意なしで送信できる。

### 電気通信事業法

**電気通信事業法**は、電気通信事業者を規律する法律である。**通信の秘密**を保護し、通信事業者が業務上知り得た通信内容や送受信者を漏らすことを禁止する。

2023年施行の改正では、Webサイトやアプリが利用者の情報を外部に送信する際の通知・公表（**外部送信規律**）が加わった。

## 試験での問われ方

- サイバーセキュリティ基本法は「事業者に具体的な対策を義務づけ、違反に罰則がある」とする選択肢が誤り。**努力義務**と基本理念を定める法律
- 「不正アクセス禁止法に該当するもの」は**ネットワーク経由で他人のIDでログインする**行為。目の前の他人のPCの操作、認証なしのサーバへの接続、推測しただけで入力しない、は該当しない。他人のID・パスワードを無断で第三者に教える助長行為は処罰されるが、管理者の不備に罰則はない
- 刑法の罪は事例から選ばせる。DoS攻撃と改ざんは業務妨害、不正データで利益を得たら使用詐欺、マルウェア作成は不正指令電磁的記録。**記憶媒体経由**でマルウェアを持ち込んだ場合は不正アクセス禁止法ではなく刑法
- 電子署名法は「**押印と同様の効力**」（真正な成立の推定）。認証業務は民間も行え、認定は任意で、暗号技術も限定されない
- 発信者情報開示請求は**情報流通プラットフォーム対処法**（旧プロバイダ責任制限法）。不正アクセス禁止法や電気通信事業法と混同させる選択肢に注意
- 特定電子メール法は「**オプトイン**」が原則で、規制対象は送信者と送信委託者。「オプトアウト方式なら事前同意不要」は誤り

## 用語集

- **サイバーセキュリティ基本法**: サイバーセキュリティの基本理念と国・地方公共団体・事業者などの責務を定めた基本法。事業者の責務は努力義務。
- **サイバーセキュリティ戦略**: サイバーセキュリティ基本法に基づき政府が閣議決定する基本計画。サイバーセキュリティ戦略本部が案を作る。
- **サイバーセキュリティ戦略本部**: 内閣に置かれる推進体制。事務局は2025年7月1日にNISCから改組された国家サイバー統括室。
- **サイバーセキュリティ協議会**: 2018年改正で設けられた官民の情報共有の枠組み。構成員には守秘義務がある。
- **重要社会基盤事業者**: 電力・金融・医療・交通など国民生活の基盤となるサービスを提供する事業者（重要インフラ事業者）。
- **不正アクセス禁止法**: 不正アクセス行為、識別符号の不正取得・保管、助長行為、フィッシングを禁止し処罰する法律。
- **アクセス制御機能**: 識別符号（ID・パスワードなど）を確認して利用を制限する機能。この機能のあるコンピュータへの行為だけが不正アクセス禁止法の対象。
- **識別符号**: 利用者を識別するためにアクセス管理者が付与する符号。パスワードや指紋などの生体情報を含む。
- **不正アクセス行為**: ネットワーク経由で、他人の識別符号の入力またはセキュリティホール攻撃により、制限されたコンピュータを利用できる状態にする行為。
- **不正アクセス行為を助長する行為**: 業務その他正当な理由なく、他人の識別符号を第三者に提供する行為。提供しただけで処罰される。
- **アクセス管理者**: 特定電子計算機の利用を管理する者。識別符号の管理などの防御措置を講じる努力義務がある。
- **不正指令電磁的記録に関する罪**: ウイルス作成罪。正当な理由なく実行目的でマルウェアを作成・提供・供用・取得・保管する行為を処罰する刑法の罪。
- **電子計算機損壊等業務妨害罪**: コンピュータやデータの損壊、虚偽の情報や不正な指令による動作妨害で業務を妨害する罪。DoS攻撃や改ざんが該当。
- **電子計算機使用詐欺罪**: コンピュータに虚偽の情報や不正な指令を与えて財産上不法の利益を得る罪。人を欺かない点が通常の詐欺と異なる。
- **電磁的記録不正作出及び供用罪**: 権利・義務・事実証明に関する電磁的記録を不正に作成し、または使用する罪。
- **支払用カード電磁的記録不正作出等罪**: クレジットカードなどの磁気情報を不正に作成・所持・取得する罪。スキミングが該当。
- **電子署名法**: 本人性と非改ざん性を満たす電子署名が付された電磁的記録を真正に成立したものと推定する法律。押印と同様の効力を認める。
- **認定認証事業者**: 電子証明書を発行する認証業務について、一定の基準を満たし主務大臣の認定を受けた事業者。認定は任意で、民間事業者もなれる。
- **電子証明書**: 公開鍵とその持ち主の対応を認証局が証明する電子データ。電子署名の検証に使う。
- **情報流通プラットフォーム対処法**: 旧プロバイダ責任制限法。プロバイダの損害賠償責任の制限と発信者情報開示を定め、2025年4月施行の改正で大規模プラットフォーム事業者の削除対応義務が加わった。
- **発信者情報開示請求**: 権利を侵害された者がプロバイダに対して投稿者のIPアドレスや氏名などの開示を求める権利。
- **特定電子メール法**: 広告宣伝メールに事前同意（オプトイン）を義務づけ、送信者情報の表示や受信拒否手段の提供を求める法律。
- **送信委託者**: 広告宣伝メールの送信を他の事業者に委託した者。送信者とともに特定電子メール法の規制対象になる。
- **オプトイン**: あらかじめ受信者の同意を得てから送信する方式。特定電子メール法の原則。
- **電気通信事業法**: 電気通信事業者を規律する法律。通信の秘密の保護や外部送信規律を定める。
- **通信の秘密**: 通信の内容だけでなく送受信者や日時なども含めて第三者に知られない権利。憲法と電気通信事業法で保護される。
