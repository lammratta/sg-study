## 要点

- 経営はPDCAで回す。CEOは経営全体、CIOは情報システム、**CISO**は情報セキュリティ、CDOはデジタル戦略、CPOは個人情報保護の責任者
- 組織形態は職能別（機能ごと）、**事業部制**（製品・地域ごと）、マトリックス（二重の指揮系統）、プロジェクト組織（有期）の特徴で区別する
- **QC七つ道具**は図の形と目的で区別する（パレート図は重点の把握、特性要因図は原因と結果の整理）。回帰分析は関係式の推定、デシジョンツリーは期待値で選択肢を比較する
- データ利活用は、収集→加工（**データクレンジング**など）→分析→可視化・活用の順に進める
- **損益分岐点売上高**＝固定費÷（1－変動費率）。売上高－売上原価＝売上総利益（粗利）、さらに販管費を引くと営業利益
- **先入先出法**は古い仕入から順に払い出したとみなす評価法で、期末在庫は新しい仕入から残る。貸借対照表は資産＝負債＋純資産、流動比率は短期の支払能力

## 解説

### 経営管理と組織

経営管理は、計画（Plan）→実行（Do）→評価（Check）→改善（Act）の**PDCA**サイクルで事業を継続的に改善する活動である。経営層の役職は、次のように責任範囲で区別する。

| 役職 | 責任範囲 |
| --- | --- |
| CEO（最高経営責任者） | 経営全体 |
| CIO（最高情報責任者） | 情報システム |
| CDO（最高デジタル責任者） | デジタル活用による事業変革 |
| CISO（最高情報セキュリティ責任者） | 情報セキュリティ |
| CPO（最高プライバシー責任者） | 個人情報保護 |

組織形態は、次の特徴で区別する。

| 組織形態 | 特徴 |
| --- | --- |
| 職能別組織 | 製造・販売・経理など機能ごとに部門を分ける。専門性は高いが部門間の連携が弱い |
| 事業部制組織 | 製品・地域・顧客ごとに事業部を置き利益責任をもたせる。意思決定は速いが機能の重複が生じる |
| マトリックス組織 | 職能と事業の二重の指揮系統をもつ。柔軟だが命令系統が複雑 |
| プロジェクト組織 | 特定の目的のために期間限定で編成し、終了後に解散する |

### 人材・リスク・社会的責任

人材面では、**リーダーシップ**とコミュニケーションを重視し、ケーススタディやeラーニング、新技術に対応する学び直し（**リスキリング**）で育成する。

リスクマネジメントでは、**事業影響度分析**（BIA）で重要業務と停止時の影響を評価してBCP（事業継続計画）を策定し、BCM（事業継続マネジメント）として維持・改善する。

企業は株主だけでなく、企業活動の影響を受けるさまざまな**ステークホルダ**（利害関係者）に責任を負う。これを**CSR**（企業の社会的責任）という。企業の活動がどのステークホルダに便益や影響を与えるかは、次のように対応付けて考える。

| ステークホルダ | 主な関心・受ける影響 |
| --- | --- |
| 株主・投資家 | 配当、株価、企業価値 |
| 顧客・消費者 | 製品やサービスの品質、価格、安全性 |
| 従業員 | 雇用の安定、賃金、労働環境 |
| 取引先（仕入先、下請企業） | 公正な取引条件、取引の継続 |
| 地域社会（近隣の住民） | 地元での雇用の創出、騒音・排水・排気などの環境対策、地域への貢献 |
| 行政 | 法令の遵守、納税 |

経営の透明性と健全性を確保し、経営者を監督する仕組みが**コーポレートガバナンス**である。

### 業務分析の手法

業務分析や品質管理では**QC七つ道具**を使う。主に数値データを扱う手法で、図の形と目的で区別する。

| 手法 | 形と使い方 |
| --- | --- |
| パレート図 | 項目を件数の多い順に棒グラフで並べ、累積比率を折れ線で重ねる。重点的に取り組む項目を絞り込む |
| 特性要因図 | 結果（特性）と、それに影響する原因（要因）の関係を、魚の骨のような形に体系的に整理する |
| 管理図 | 時系列のデータを折れ線で描き、上下の管理限界線を使って工程の異常を見つける |
| ヒストグラム | データを区間に分け、区間ごとの件数（度数）を棒グラフにして、分布やばらつきをつかむ |
| 散布図 | 2つの変数を縦軸と横軸にとって点を打ち、相関の有無や強さを見る |
| チェックシート | 点検項目や発生件数を記録しやすく整理した表。漏れのないデータ収集や点検に使う |
| 層別 | データを機械別・担当者別などのグループに分けて比較し、違いを見つける |

**魚の骨の形なら特性要因図、管理限界線があれば管理図**、度数の棒グラフならヒストグラム、累積比率の折れ線があればパレート図と見分ける。言語データ（意見や事実を書いた文章）を整理する手法は**新QC七つ道具**といい、親和図法、連関図法、系統図法などがある。

パレート図を使い、上位から累積70〜80%をA、次をB、残りをCと分けて重点対象を決めるのが**ABC分析**である。

発想や予測の手法には次のものがある。

- **ブレーンストーミング**: 批判禁止・質より量を原則に、自由に多数のアイデアを出す
- **デルファイ法**: 専門家へのアンケートを繰り返して意見を収束させる

OR・IEの基本的な手法には次のものがある。

- **サンプリング**: 一部を調べて全体を推定する
- **シミュレーション**: モデルを使って実験し、結果を予測する
- **回帰分析**: 2つの変数の関係を式で表し、予測に使う

### 意思決定と期待値

意思決定では、各結果の値に発生確率を掛けて合計した**期待値**を、選択肢を枝分かれで表した**デシジョンツリー**で比較する。計算の手順は次のとおり。

1. 案ごとに、起こりうる結果それぞれについて「確率×金額」を求める
2. それらを合計して、その案の期待値とする
3. **利益なら期待値が最大の案、費用なら期待値が最小の案**を選ぶ

例題1: 新製品を投入する案は、成功（確率0.6）で利益300万円、失敗（確率0.4）で損失200万円。投入しない案は利益0円。投入案の期待値は300×0.6＋（－200）×0.4＝100万円で、投入しない案の0円より大きいため投入案を選ぶ。

### データ利活用（新制度で追加）

2027年度の新制度では、データ分析・データ利活用とAI利活用の観点が追加される。社会全体でも、サイバー空間と現実空間を高度に融合させる**Society5.0**や、データに基づいて意思決定する**データ駆動型社会**が目指されている。ビッグデータから価値を引き出す学問・技術が**データサイエンス**である。

データ利活用は次の順に進める。

1. **収集**: センサー、業務システムの記録、Webなどからデータを集める。Webクローリング（Webページの自動巡回取得）やスクレイピング（ページからの情報抽出）を使うが、利用規約や著作権、個人情報の扱いに注意する
2. **加工**: 集めたデータを分析に使える状態に整える（前処理）。誤りや重複、表記の揺れ、欠けた値を直したり除いたりする**データクレンジング**や、ノイズの除去、形式の統一を行う
3. **分析**: 統計手法や、データから規則性を学習する**機械学習**を使って傾向やパターンを見つける。似たデータをグループに分けるクラスタリング、文章を解析する自然言語処理、関係を式で表す回帰分析などを使う
4. **可視化・活用**: グラフやダッシュボードで結果を分かりやすく示し、意思決定や事業戦略の立案に生かす

結果の精度と偏りには注意が必要である。

- **統計的バイアス**: データの収集方法に起因する偏り（回答者の偏りなど）
- **認知バイアス**: 人の思い込みによる判断の偏り（仮説に合う情報だけを集めるなど）

どちらも誤った結論を導く。**AIでも学習データの偏りがそのまま結果の偏りになる**。

### 損益計算書と製造原価

**損益計算書**は一定期間の経営成績を示す。利益は次の順に求める。

- 売上高－売上原価＝**売上総利益**（粗利益）
- 売上総利益－販売費及び一般管理費＝**営業利益**
- 営業利益＋営業外収益－営業外費用＝経常利益

**売上原価**は、売上高に対応する商品や製品の原価である。商品を仕入れて売る場合は、期首商品棚卸高＋当期商品仕入高－期末商品棚卸高で求める。製造業では、製造原価明細書で当期に完成した製品の原価を計算し、それを使って売上原価を求める。

1. 当期総製造費用＝材料費＋労務費＋経費
2. 当期製品製造原価＝当期総製造費用＋期首仕掛品棚卸高－期末仕掛品棚卸高
3. 売上原価＝期首製品棚卸高＋当期製品製造原価－期末製品棚卸高
4. 売上総利益＝売上高－売上原価

**仕掛品**は製造途中の製品である。**期首の在庫は当期の原価に足し、期末に残った在庫は差し引く**という考え方を、仕掛品と製品の2段階で使う。

例題2: 材料費300、労務費200、経費100、期首仕掛品50、期末仕掛品80、期首製品40、期末製品60、売上高900、販売費及び一般管理費200（単位は千円）のとき、売上総利益と営業利益を求める。

当期総製造費用は300＋200＋100＝600、当期製品製造原価は600＋50－80＝570、売上原価は40＋570－60＝550である。売上総利益は900－550＝350千円、営業利益は350－200＝150千円になる。

### 損益分岐点と減価償却

費用は、売上に関係なく一定の**固定費**（家賃、人件費、減価償却費）と、売上に比例する**変動費**（材料費、仕入原価）に分けられる。

売上高に対する変動費の割合が**変動費率**で、利益がちょうど0になる売上高が**損益分岐点売上高**である。計算の手順は次のとおり。

1. 変動費率＝変動費÷売上高
2. 損益分岐点売上高＝固定費÷（1－変動費率）
3. 目標利益を出すのに必要な売上高＝（固定費＋目標利益）÷（1－変動費率）

例題3: 固定費600万円、売上高1,500万円のときの変動費が600万円の企業では、変動費率は600÷1,500＝0.4なので、損益分岐点売上高は600÷（1－0.4）＝1,000万円である。利益300万円を出すのに必要な売上高は（600＋300）÷0.6＝1,500万円になる。

**減価償却**は、固定資産の取得原価を耐用年数にわたって費用に配分する手続である。定額法では毎年同額を計上し、（取得原価－残存価額）÷耐用年数で求める。たとえば取得原価600万円、残存価額0円、耐用年数5年なら、毎年120万円を費用にする。

機器の調達には購入のほか、長期契約で中途解約が難しい**リース**、短期で柔軟な**レンタル**がある。

### 在庫評価

在庫の払出単価の決め方（在庫の評価方法）には次のものがある。

- **先入先出法**: 先に仕入れたものから順に払い出したとみなす。期末在庫は新しい仕入分から残る
- **移動平均法**: 仕入のたびに、手元の在庫と合わせた平均単価を計算し直す
- **総平均法**: 期首在庫と期中の仕入の合計金額を合計数量で割った、期間の平均単価で評価する
- **最終仕入原価法**: 期末在庫のすべてを、最後に仕入れたときの単価で評価する

例題4: 期首在庫100個（単価100円）、期中仕入200個（単価120円）、期中払出250個のとき、先入先出法の払出原価は100×100＋150×120＝28,000円、期末在庫は50個×120円＝6,000円である。

**先入先出法で期末在庫を評価するときは、最も新しい仕入から順に、期末の数量に達するまで数える**。

例題5: 期首在庫20個（単価100円）、4月仕入30個（単価110円）、8月仕入50個（単価120円）で、期末在庫が60個のときの期末在庫評価額を求める。

- 先入先出法: 8月分50個×120＝6,000円、残り10個は4月分で10×110＝1,100円、合計7,100円
- 総平均法: 平均単価は（20×100＋30×110＋50×120）÷100個＝11,300÷100＝113円なので、60個×113＝6,780円
- 最終仕入原価法: 60個×120＝7,200円

### 財務諸表

**貸借対照表**は決算日時点の財政状態を示し、資産＝負債＋純資産が成り立つ。

- 資産: 1年以内に現金化できる流動資産、長期に使う固定資産（有形資産・無形資産）、繰延資産
- 負債: 1年以内に返済する流動負債と、それより長期の固定負債

**流動比率**（流動資産÷流動負債）は短期の支払能力を表し、100%超が目安である。**キャッシュフロー計算書**は、営業・投資・財務の活動ごとに現金の増減を示す。

## 試験での問われ方

- 損益分岐点売上高の計算は定番。**変動費率は変動費÷売上高**で求めてから公式に当てはめる。売上総利益と営業利益の違い（販管費を引く前か後か）も問われる
- 製造原価からの計算は「**期首を足し、期末を引く**」を仕掛品と製品の2段階で行う
- 先入先出法の期末在庫は**新しい仕入分から数える**。移動平均法・総平均法との違いが問われ、総平均法や最終仕入原価法で計算した値が誤りの選択肢に並ぶ
- 期待値による意思決定は**確率×金額の合計**を比較する。費用の比較なら最小の案を選ぶ
- QC七つ道具は説明文から図を特定させる（**魚の骨は特性要因図**）。パレート図とABC分析の関係、デルファイ法（専門家への反復アンケート）、ビッグデータ活用の段階（クレンジングは加工、クラスタリングは分析）も出る
- CIO・CISO・CPOの責任範囲、事業部制とマトリックス組織の特徴、**CSRの便益を受けるステークホルダ**が問われる。新制度ではデータ利活用のバイアス（統計的・認知）が問われる見込み

## 用語集

- **PDCA**: 計画・実行・評価・改善を繰り返して継続的に改善する管理サイクル。
- **CEO・CIO・CDO・CISO・CPO**: 経営全体、情報システム、デジタル戦略、情報セキュリティ、個人情報保護それぞれの最高責任者。
- **職能別組織・事業部制組織**: 機能ごとに分けた組織と、製品や地域ごとに利益責任をもつ事業部を置いた組織。
- **マトリックス組織・プロジェクト組織**: 職能と事業の二重の指揮系統をもつ組織と、特定の目的のために期間限定で編成する組織。
- **リスキリング**: 新しい技術や業務に対応するための学び直し。
- **BCP・BCM・BIA**: 事業継続計画、それを維持改善する事業継続マネジメント、重要業務と停止時の影響を評価する事業影響度分析。
- **CSR・ステークホルダ**: 企業の社会的責任と、その対象となる利害関係者（株主、顧客、従業員、取引先、地域社会など）。
- **コーポレートガバナンス**: 経営の透明性と健全性を確保し、経営者を監督する仕組み。
- **Society5.0・データ駆動型社会**: サイバー空間と現実空間を融合させた社会と、データに基づいて意思決定する社会。
- **QC七つ道具**: パレート図、管理図、ヒストグラム、散布図、特性要因図、チェックシート、層別の品質管理手法。
- **特性要因図**: 結果と、それに影響する原因の関係を魚の骨のような形に整理した図。
- **新QC七つ道具**: 親和図法、連関図法、系統図法など言語データを整理する手法。
- **パレート図・ABC分析**: 件数順に並べ累積比率で重点対象を見つける図と、それを用いてA・B・Cに分類する分析。
- **サンプリング・シミュレーション・回帰分析**: 一部の調査から全体を推定する手法、モデルで実験する手法、変数間の関係を式で表して予測する手法。
- **ブレーンストーミング・デルファイ法**: 批判せず自由に多数のアイデアを出す発想法と、専門家へのアンケートを繰り返して意見を収束させる予測手法。
- **デシジョンツリー・期待値**: 選択肢と結果を枝分かれで表した図と、結果の値に確率を掛けて合計した値。
- **Webクローリング・スクレイピング**: Webページを自動で巡回収集する技術と、ページから必要な情報を抽出する技術。
- **データサイエンス**: 統計や機械学習を使ってデータから価値を引き出す学問・技術。
- **統計的バイアス・認知バイアス**: データの収集方法に起因する偏りと、人の思い込みによる判断の偏り。
- **固定費・変動費・変動費率**: 売上に関係なく一定の費用、売上に比例する費用、売上高に対する変動費の割合。
- **損益分岐点**: 売上高と費用が等しく利益が0になる点。固定費÷（1－変動費率）で求める。
- **粗利益・営業利益**: 売上高から売上原価を引いた利益と、さらに販売費及び一般管理費を引いた利益。
- **製造原価・仕掛品**: 製品を作るのにかかった材料費・労務費・経費と、製造途中の製品。当期製品製造原価は当期総製造費用に期首仕掛品を足し、期末仕掛品を引いて求める。
- **減価償却**: 固定資産の取得原価を耐用年数にわたって費用として配分する手続。
- **先入先出法**: 先に仕入れた在庫から順に払い出したとみなして原価を計算する方法。期末在庫は新しい仕入分から残る。
- **貸借対照表**: 決算日時点の資産、負債、純資産を示す財務諸表。資産＝負債＋純資産。
- **流動資産・固定資産・繰延資産**: 1年以内に現金化する資産、長期に使う資産、効果が将来に及ぶ費用を資産計上したもの。
- **流動負債・固定負債**: 1年以内に返済する負債と、それより長期の負債。
- **流動比率**: 流動資産÷流動負債。短期の支払能力を示す。
- **キャッシュフロー計算書**: 営業・投資・財務の活動ごとに現金の増減を示す財務諸表。
