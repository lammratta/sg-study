## 要点

- コンプライアンスは**法令だけでなく社会規範・倫理・社内規程**を守ること。コーポレートガバナンスは経営を監視する仕組みで、内部統制は会社法と金融商品取引法が整備を求める
- 公益通報者保護法は通報者の解雇や**不利益な取扱いを禁止**し、従業員301人以上の事業者に内部通報体制の整備を義務づける
- e-文書法は法令で保存が義務づけられた書面の電子保存を認める通則法、電子帳簿保存法は国税関係の帳簿書類の電子保存を定め、**電子取引データの電子保存は義務**
- 情報倫理では、誤情報（ミスインフォメーション）・偽情報（ディスインフォメーション）・悪意ある情報（マルインフォメーション）を区別し、**ファクトチェック**で確認する
- 技術者倫理は**公衆の安全・健康・福利を最優先**し、組織の利益と対立する場合も専門家として責任を果たすこと
- 新制度（2027年度）では**AI倫理**が加わる。AI事業者ガイドラインの人間中心・安全性・公平性・透明性などの原則と、生成AI利用の注意点を押さえる

## 解説

### コンプライアンスとコーポレートガバナンス

**コンプライアンス**は法令遵守と訳されるが、**法律だけでなく社会規範、倫理、業界の自主ルール、社内規程を守ることまで含む**。情報セキュリティの文脈では、次のものを守ることがコンプライアンスにあたる。

- 個人情報保護法や不正競争防止法などの法令
- 取引先との契約
- 自社のセキュリティポリシー

**コーポレートガバナンス**（企業統治）は、株主など利害関係者の立場から経営者を監視し、不正や暴走を防いで企業価値を高める仕組みである。柱になるのは、取締役会・監査役・社外取締役などの機関設計と、東京証券取引所のコーポレートガバナンス・コードである。

### 内部統制と関連法規

**内部統制**は、次の目的を達成するために組織内に組み込まれるプロセスである。

- 業務の有効性・効率性
- 報告の信頼性
- 法令遵守
- 資産の保全

内部統制の整備を求める法律は次の2つである。

| 法律 | 求める内容 |
| --- | --- |
| 会社法 | 大会社などに内部統制システムの整備を求める |
| 金融商品取引法 | 上場企業に、財務報告に係る**内部統制報告書**の提出と監査を求める（いわゆるJ-SOX） |

情報システムへの統制（IT統制）も、内部統制の要素である。

### 公益通報者保護法

**公益通報者保護法**は、労働者などが勤務先の法令違反を通報した場合に、通報者を守る法律である。通報先は事業者内部、行政機関、報道機関などである。

- 通報を理由とする解雇は無効になる
- 降格・減給などの**不利益な取扱い**は禁止される

2022年6月施行の改正で、**従業員301人以上の事業者**に内部通報窓口の設置など体制整備が義務づけられた（300人以下は努力義務）。あわせて、通報対応の従事者に守秘義務が課された。通報者を保護することで、不正の早期発見と是正につなげる制度である。

### 電子文書に関する法律

| 法律 | 内容 |
| --- | --- |
| e-文書法 | 法令で保存が義務づけられた書面を、民間事業者が電磁的記録で保存・作成・交付できるようにする通則法（2005年施行） |
| 電子帳簿保存法 | 国税関係の帳簿・書類の電子保存を認める法律。電子帳簿等保存（電子的に作成した帳簿・書類をデータのまま保存）、スキャナ保存（紙の書類を画像で保存）、電子取引データ保存の3区分がある |
| デジタル社会形成基本法 | 2021年施行。IT基本法に代わり、デジタル社会の基本理念とデジタル庁の設置を定める |
| 官民データ活用推進基本法 | 2016年施行。オープンデータの推進や官民データ活用推進基本計画を定める |
| 情報公開法 | 行政機関が保有する文書の開示請求権を定める。個人情報や安全保障に関わる不開示情報を除いて開示される |

**電磁的記録**は、電子的・磁気的な方式で作られ、コンピュータで処理される記録（電子データ）のことである。

電子帳簿保存法では、**電子取引のデータは電子のまま保存することが義務**である。電子取引とは、請求書や領収書などをメールやWebでやり取りする取引のことで、受け取った側も送った側も保存の対象になる。保存では、次の2つの要件を満たす必要がある。

- **真実性**: タイムスタンプや訂正・削除履歴の確保により、改ざんされていないことを示せる
- **可視性**: 日付・金額・取引先で検索できる

### 技術者倫理

**技術者倫理**は、技術者が専門職として**公衆の安全・健康・福利を最優先**し、所属組織の利益や上司の指示と対立しても、専門家としての判断に責任を持つという考え方である。情報処理学会の倫理綱領などが指針になる。

サイバー空間の脅威に対する倫理的な対応として、次のことが求められる。

- 脆弱性を見つけたら、無断で公表したり悪用したりせず、責任ある開示の手続をとる（IPAへの脆弱性関連情報の届出など、**情報セキュリティ早期警戒パートナーシップ**の枠組み）
- 他人のシステムに不正アクセスしない
- 違法な情報を拡散しない

### 情報倫理と情報の真偽

**情報倫理**は、情報社会で一人ひとりが守るべき規範である。ネチケット（ネットワーク上のマナー）や、デジタル技術を責任をもって使う市民としての資質である**デジタル・シチズンシップ**を含む。

SNS時代に特に重要なのが、情報の真偽の見極めである。

| 用語 | 意味 |
| --- | --- |
| ミスインフォメーション | 誤った情報を**悪意なく**拡散すること（誤情報） |
| ディスインフォメーション | **意図的**に作られ拡散される虚偽の情報（偽情報） |
| マルインフォメーション | **事実に基づく**が、私的な情報の暴露など害を与える目的で拡散される情報 |
| フェイクニュース | 虚偽の内容をニュースの体裁で広める情報 |
| ファクトチェック | 情報の真偽を根拠に照らして検証すること |
| デジタルタトゥー | 一度ネットに投稿した情報は消えずに残り続けること |

### 有害情報対策とソーシャルメディアポリシー

青少年を有害情報から守るため、青少年インターネット環境整備法は、携帯電話事業者などに**フィルタリング**の提供を義務づけている。保護者が利用を制限する**ペアレンタルコントロール**も普及している。

企業は、従業員のSNS利用について**ソーシャルメディアポリシー**（ガイドライン）を整備する。主に次の内容を定める。

- 業務上の秘密や顧客情報の投稿禁止
- 会社を代表する発言と個人の発言の区別
- 炎上時の対応

### AI倫理（新制度で追加）

2027年度の新制度では、「情報倫理・AI倫理」の観点が加わる。

政府の「**AI事業者ガイドライン**」（総務省・経済産業省、2024年）は、次のような原則を示し、開発者・提供者・利用者それぞれの責務を整理している。

- 人間中心
- 安全性
- 公平性
- プライバシー保護
- セキュリティ確保
- 透明性
- アカウンタビリティ

2025年には、人工知能関連技術の研究開発と活用を推進する法律（**AI推進法**）が成立した。国の基本計画と、事業者が国の施策に協力する努力義務を定めている。

実務では、生成AIの利用について次のようなルールを定めることが求められる。

- 機密情報や個人情報を入力しない
- 出力の誤り（ハルシネーション）を検証する
- 学習データの偏りによる差別的な出力に注意する
- 著作権を侵害する生成物を使わない

### 情報セキュリティ関連のガイドライン

法律の下で実務の基準となるガイドラインも試験範囲である。

| 対象 | ガイドライン・制度 | 作成・運営 |
| --- | --- | --- |
| 政府機関 | 政府機関等のサイバーセキュリティ対策のための**統一基準群**。各府省庁はこれに基づいて対策基準を作る | 国家サイバー統括室（旧NISC） |
| 企業 | サイバーセキュリティ経営ガイドライン。経営者が認識すべき3原則と、指示すべき重要10項目を示す | 経済産業省・IPA |
| 企業 | 情報セキュリティ管理基準 | 経済産業省 |
| 中小企業 | 中小企業の情報セキュリティ対策ガイドライン | IPA |
| 組織全般 | 組織における内部不正防止ガイドライン | IPA |
| 組織全般 | 情報セキュリティ10大脅威（毎年公表） | IPA |
| 中小企業 | SECURITY ACTION（自ら対策を宣言する制度） | IPA |

## 試験での問われ方

- コンプライアンスを「法令遵守のみ」とする選択肢は不十分。**社会規範や社内規程**の遵守を含む
- 内部統制の根拠法は会社法と金融商品取引法。「**内部統制報告書**」は金融商品取引法が上場企業に求める
- 公益通報者保護法は「通報者への**不利益取扱いの禁止**」と「301人以上に体制整備義務」の2点
- e-文書法と電子帳簿保存法の違いは「民間の書面全般の通則法」と「国税関係帳簿書類」。**電子取引データの電子保存が義務**である点に注意
- ミスインフォメーション（**悪意なし**）とディスインフォメーション（意図的）の区別、マルインフォメーション（事実だが有害）を問う問題が新しい
- 技術者倫理では「上司の指示に従って欠陥を隠す」が誤り。**公衆の安全を優先**する選択肢を選ぶ

## 用語集

- **コンプライアンス**: 法令だけでなく社会規範、倫理、社内規程を守ること。情報セキュリティ関連法規や契約の遵守を含む。
- **コーポレートガバナンス**: 株主など利害関係者の立場から経営を監視・規律し、企業価値を高める仕組み。
- **内部統制**: 業務の有効性・効率性、報告の信頼性、法令遵守、資産の保全を達成するために組織に組み込まれるプロセス。
- **会社法**: 会社の設立・運営を定める法律。大会社などに内部統制システムの整備を求める。
- **金融商品取引法**: 上場企業に財務報告に係る内部統制報告書の提出と監査を義務づける法律（J-SOX）。
- **公益通報者保護法**: 法令違反を通報した労働者などを解雇や不利益取扱いから守り、301人以上の事業者に内部通報体制を義務づける法律。
- **デジタル社会形成基本法**: デジタル社会の基本理念とデジタル庁の設置を定めた法律。2021年にIT基本法に代わって施行。
- **官民データ活用推進基本法**: 官民のデータ活用とオープンデータの推進を定めた法律。
- **e-文書法**: 法令で保存が義務づけられた書面を電磁的記録で保存できるようにする通則法。
- **電磁的記録**: 電子的・磁気的方式で作られ、コンピュータで処理される記録。電子データのこと。
- **電子帳簿保存法**: 国税関係の帳簿書類の電子保存を認める法律。電子取引データは電子のまま保存する義務がある。
- **情報公開法**: 行政機関の保有する文書の開示請求権を定める法律。
- **技術者倫理**: 技術者が公衆の安全・健康・福利を最優先し、専門職として責任ある判断をする規範。
- **情報倫理**: 情報社会で守るべき規範。ネチケットやデジタル・シチズンシップを含む。
- **デジタル・シチズンシップ**: デジタル技術を責任をもって安全に使い、社会に参加する市民としての資質。
- **フェイクニュース**: 虚偽の内容をニュースの体裁で広める情報。
- **ミスインフォメーション**: 悪意なく拡散される誤った情報（誤情報）。
- **ディスインフォメーション**: 意図的に作られ拡散される虚偽の情報（偽情報）。
- **マルインフォメーション**: 事実に基づくが、害を与える目的で拡散される情報。私的情報の暴露など。
- **ファクトチェック**: 情報の真偽を根拠に照らして検証すること。
- **デジタルタトゥー**: ネットに投稿した情報が消えずに残り続けること。
- **フィルタリング**: 有害サイトへのアクセスを制限する仕組み。青少年インターネット環境整備法が提供を義務づける。
- **ペアレンタルコントロール**: 保護者が子どもの端末の利用時間やアクセス先を制限する機能。
- **ソーシャルメディアポリシー**: 従業員のSNS利用に関する企業の方針。機密情報の投稿禁止や炎上時の対応を定める。
- **AI事業者ガイドライン**: 総務省・経済産業省が示すAIの開発・提供・利用の指針。人間中心、安全性、公平性、透明性などの原則を示す（新制度で追加）。
- **政府機関等の統一基準**: 国家サイバー統括室が定める政府機関向けのセキュリティ対策基準群。各府省庁の対策基準の基礎。
- **サイバーセキュリティ経営ガイドライン**: 経済産業省とIPAが示す、経営者が認識すべき3原則と指示すべき重要10項目。
- **情報セキュリティ早期警戒パートナーシップ**: 脆弱性関連情報をIPAが受け付け、JPCERT/CCが開発者と調整して公表する責任ある開示の枠組み。
